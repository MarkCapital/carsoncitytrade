## Implementation
Public submission admission is SQLite-backed with an atomic reservation before email: 2/IP/10min, 3/email/24h, 6/email/7days, duplicate/6h. Email uses casefold and is independent of IP, phone and content. State retains hashes only, expires after seven days, survives restart, and serializes concurrent admission. No language filtering. No email-domain or notification-sender blocking. Send failure releases quota; a crash after reservation conservatively retains quota. SQLite or verification outages reject only submissions; /health remains available. Gmail and network verification execute off the async event loop.

CARSON_TURNSTILE_REQUIRED=1 enforces Siteverify, exact hostname carsoncitytradingpost.com and action contact. Missing/malformed tokens, success=false (including expired/replayed), incorrect hostname/action and verification timeout fail closed. It defaults OFF for staged compatibility; this branch is not fully activated protection until configured. Dry runs never send mail or exempt real submissions. The only send exemption is a loopback request WITHOUT X-Forwarded-For, for the existing VM watchdog. Caddy sets that header on all proxied requests; Uvicorn trusts only the loopback proxy. Keep the backend loopback-bound and do not broaden forwarded-allow-ips.
